# Contributing

Thanks for wanting to add an app. Keep it simple — open a Pull Request editing `README.md` (and `mac-apps-notion.csv` if you can).

## Criteria

An app must be:

1. **Run on macOS** — a real Mac app (native or desktop), not a web-only service.
2. **Useful and maintained** — actively developed, with a working download or repo.
3. **Worth a designer's, developer's, or founder's time** — essential or best-in-class, not a niche demo.
4. **Open source preferred** — this list leans open source; lead the description with "Open-source …" when it applies. Best-in-class paid/freemium apps are welcome too.
5. **Fits an existing category** — Developer Tools, Design & Creative, Notes & Writing, Tasks & Productivity, Window Management & Launchers, Menu Bar & System, Files & Utilities, Media & Screen Recording, Communication, Privacy & Security, or Business & Finance. Don't invent a new category without opening an issue first.

## Format

Add the app at the end of the most relevant category table. Use this format:

```
| <next #> | [App Name](https://example.com) | One-line description |
```

- Keep descriptions under ~80 characters and **no trailing period** (unified style).
- Lead with the function, not marketing language ("Open-source window manager" beats "The best window manager ever").
- Use the official homepage or GitHub URL — not a mirror or affiliate link.

If you can, add the same row to `mac-apps-notion.csv` so the spreadsheet stays in sync.

## Process

1. Fork the repo.
2. Edit `README.md` (and the CSV if possible).
3. Open a PR with a short justification — a link to the app and one sentence on why it fits.
4. One app per PR (makes review easier).

Removals (dead apps, broken links, apps that went paid-only) are welcome too — same flow.

## Not accepted

- Web-only services with no Mac app.
- Abandoned or broken apps.
- Affiliate links, referral codes, SEO spam, or self-promotion.
